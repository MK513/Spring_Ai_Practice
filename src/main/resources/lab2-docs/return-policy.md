# 반품·교환 정책

## 단순 변심 반품

상품을 받은 날부터 **7일 이내**에 반품을 신청할 수 있습니다.
단순 변심으로 반품하는 경우 **왕복 배송비는 고객이 부담**합니다. 편도 3,000원, 왕복 6,000원입니다.
포장을 뜯었거나 사용한 흔적이 있으면 단순 변심 반품이 되지 않습니다.

## 불량·오배송

상품에 하자가 있거나 주문과 다른 상품이 왔을 때는 받은 날부터 **30일 이내**에 신청할 수 있고,
배송비는 **회사가 전액 부담**합니다. 사진을 함께 올려 주시면 확인이 빨라집니다.

## 교환

교환은 같은 상품의 다른 색상·사이즈로만 됩니다. 다른 상품으로 바꾸려면 반품 후 다시 주문해 주세요.
교환 배송비는 단순 변심이면 고객 부담, 불량이면 회사 부담입니다.

## 반품이 안 되는 상품

- 주문 제작 상품
- 개봉하면 다시 팔 수 없는 위생용품
- 신선식품
