# SKALA 스토어 멤버십 규정 (2026-07 개정)

## 1. 등급 구분

| 등급 | 산정 기준 (직전 12개월 누적 구매액) | 적립률 |
| --- | --- | --- |
| 브론즈 | 신규 가입 ~ 30만원 미만 | 1% |
| 실버 | 30만원 이상 ~ 100만원 미만 | 2% |
| 골드 | 100만원 이상 ~ 300만원 미만 | 3% |
| 플래티넘 | 300만원 이상 | 5% |

- 등급은 매월 1일 기준으로 재산정된다.
- 등급 산정 시 취소·반품된 주문 금액은 제외한다.

## 2. 등급별 혜택

1. **브론즈**: 기본 적립, 생일 쿠폰(5,000원) 제공
2. **실버**: 브론즈 혜택 + 무료배송 쿠폰 월 1매
3. **골드**: 실버 혜택 + 무료배송 쿠폰 월 3매, 우선 고객센터 상담
4. **플래티넘**: 골드 혜택 + 전 상품 무료배송, 신상품 우선 구매권, 전담 상담 채널

## 3. 포인트 적립 및 사용

- 구매 확정 시점(수령 후 7일 경과 또는 구매확정 클릭)에 적립된다.
- 적립 포인트의 유효기간은 적립일로부터 **1년**이다.
- 1포인트 = 1원으로 사용 가능하며, 최소 사용 단위는 1,000포인트다.
- 반품·취소 시 사용한 포인트는 환불 처리와 함께 복원된다.

## 4. 등급 강등 및 유지

- 직전 12개월 누적 구매액이 하위 등급 기준에 미달하면 강등된다.
- 강등 예정 회원에게는 익월 1일 강등 7일 전 알림을 발송한다.
- 휴면 회원(1년 이상 미로그인)은 별도 심사 없이 브론즈로 조정된다.

## 5. 멤버십 해지

- 마이페이지 > 멤버십 관리에서 즉시 해지 신청이 가능하다.
- 해지 시 보유 포인트는 즉시 소멸하며 복구되지 않는다.
- 해지 후 재가입은 언제든 가능하나 등급은 브론즈부터 시작한다.
